Acesta este un site de testare pentru a-mi verifica cunoștințele în domeniul Front-End folosind tehnologii precum React / Typescript / Api-uri.

Site-ul este implementat pe paginile mele GitHub ( https://hasstyk228.github.io/Prod_Catalog_App/ )

Dacă vrei să îl rulezi local, descarcă-l și rulează proiectul în VS-code. Lansați terminalul acolo.

Instalați dependențele cu: npm install.
Porniți serverul de dezvoltare cu: npm run dev.

Aplicația mea nu îndeplinește toate condițiile stabilite, de exemplu:
1) Paginare
2) Rutare
3) Testarea
4) Pagină separată pentru coș
5) Optimizarea performanței: încărcare leneșă.

Dar am încercat să îndeplinesc toate celelalte puncte.

* Căutare
* Filtru care depinde de căutare
* Sortare care depinde de filtru
* Designul cardurilor informative
* Se încarcă datele de pe ( https://fakestoreapi.com/products )
* Se procesează încărcarea
* Gestionarea erorilor
* Coșul care apare ca meniu când dai clic pe el
* Apare un semn care arată numărul de produse adăugate în coș
* Măriți cantitatea unui produs în funcție de numărul de clicuri pe butonul de cumpărare
* Puteți mări sau micșora cantitatea fiecărui tip de produs din coșul dvs.
* Afișează costul total al unui produs în funcție de cantitatea acestuia
* Arată costul total al tuturor tipurilor și cantitatea lor de produse
* Buton pentru eliminarea unui anumit element din listă.
* Buton pentru ștergerea sau golirea întregului coș.
* Design responsiv pentru computer/tabletă/telefon
* Site-ul este implementat pe GitHub Pages
